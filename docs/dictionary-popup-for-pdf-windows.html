A dictionary popup that works inside PDFs on Windows

Acrobat, Edge and SumatraPDF have no dictionary of their own. One tray program gives all of them the same one, with no plugin and no connection.

Use a system-wide tray dictionary instead of a reader plugin. WordMeaning watches the text selection, not the application, so double-clicking a word inside Adobe Acrobat Reader, Microsoft Edge, Chrome's built-in viewer, Foxit or SumatraPDF shows the definition at your cursor and hides it again after six seconds. Every lookup is answered offline from about 86,000 WordNet entries inside the program.

Free and open source for Windows 10 and 11: installer (4.5 MB), portable .exe (9 MB).

Why PDF readers are the worst case

A browser at least has extensions. A PDF reader usually has neither a dictionary nor a plugin worth installing, and academic reading is exactly where unfamiliar words arrive in bulk. The normal workaround is to copy the word, switch to a browser, paste it, read, and then hunt for the paragraph you left. Twice a page, that is the reason the paper does not get finished.

Because the lookup here is triggered by selection at the OS level, the reader does not need to cooperate. Anything that lets you highlight text is supported by definition.

Set it up

  1. Install the installer or run the portable .exe. No administrator rights, no AutoHotkey install, nothing to configure in your PDF reader.
  2. Click through SmartScreen on first launch: More info, then Run anyway. The dialog appears for every unsigned program, and this one is unsigned because a certificate costs a few hundred dollars a year.
  3. Open your PDF and double-click a word. The popup shows the part of speech, up to two meanings, and an example sentence when the dictionary has a plain one.
  4. Carry on reading. Click, switch windows or wait six seconds. For a word the dictionary lacks, press Ctrl+Shift+D while the popup is up and it goes to a web search in your browser.

If nothing happens

  • The page is a scan. Drag across a line: if no text highlights, the file is images and there is no text layer to read. OCR the file first with your reader's own tool, then the popup works.
  • You selected more than one word. Multi-word selections are ignored on purpose, silently, so the popup never interrupts ordinary highlighting.
  • The reader blocks copying. A few DRM-protected or permission-restricted documents refuse the copy the lookup depends on. Nothing is shown in that case.
  • The popup lingers after Ctrl+Tab. Switching tabs by keyboard stays inside the same window, so it is not seen as a window switch. Click anywhere, or wait for the six-second timer.

Annotation tools are not affected. The lookup reads the selection and puts your clipboard back exactly as it was, so highlighting, copying quotes into your notes, and citation managers all keep working the way they did.

Questions

How do I look up a word in a PDF on Windows?

Run a system-wide tray dictionary rather than a reader plugin. With WordMeaning running, double-click a word in Acrobat Reader, Edge, Chrome's viewer, Foxit or SumatraPDF and the definition appears at the cursor. It works in any reader because it watches the text selection, not the application.

Why does nothing happen when I select a word in my PDF?

The file is probably a scan. An image-only PDF has no text layer, so there is nothing to select. If dragging highlights text, the layer is there; if it draws a box over a picture, it is not.

Does it need an internet connection?

No. About 86,000 WordNet entries are compiled into the program, so it works on a plane or on a machine with no network. An optional tray switch checks missing words against an online dictionary and is off until you turn it on.

Is there anything to install in Acrobat?

No. There is no plugin, no extension and no per-reader setup. The tray program is the whole thing.

Does it work with Kindle for PC?

Wherever the app allows a text selection, yes. Apps that block selection or copying entirely give the lookup nothing to read, and it stays silent.
