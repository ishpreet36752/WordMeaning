Dictionary popup tools for Windows, compared honestly

Four ways to check a word while reading, what each one actually costs you, and the reading situations where this one is the wrong pick.

There are four kinds of word lookup on Windows, and they fail in different places. A browser extension is convenient but stops at the edge of the browser. A full desktop dictionary gives you thesaurus and pronunciation, at the size of a real application. A dictionary website is always current and always a tab switch away. An AI chat window explains anything, slowly, and sends your text to a server. WordMeaning is the fifth, narrow option: a tray program that shows one definition at your cursor in any application, offline, storing nothing.

The four kinds, and where each one breaks

Browser extensions

Double-click a word on a web page and a small card appears. Excellent inside the browser, which is also the limit: an extension cannot see a PDF opened in Acrobat, a Word document, an email client or a chat app. Most call an online service for each lookup, which means each lookup leaves the machine, and extension permissions typically include reading page content.

Desktop dictionary applications

Real dictionary software (WordWeb and similar) brings definitions, a thesaurus, related words, pronunciation and word-game features, usually with a hotkey to look up the selected word. This is the right choice if you want a reference tool. The trade is scope: a window opens, and you go to it. Some are free for personal use with paid tiers, and licence terms vary between them, so read them.

Dictionary websites and search

Always current, no install, and free. Also six actions per word, a lost place in the paragraph, and a lookup history attached to whatever account you are signed in to.

An AI chat window

Unbeatable for "what does this sentence mean" and for words no dictionary has yet. Unsuited to "what does this one word mean" while reading: it is slower, it costs a context switch, and the text you paste goes to a server.

Where WordMeaning is the wrong choice

Said plainly, because a comparison that only flatters its author is worth nothing:

  • You want pronunciation. Phonetics and audio are deliberately never shown, not even when an online source provides them.
  • You want a thesaurus or translation. Neither exists here. This shows what a word means, in English, and stops.
  • You read phrases and idioms. Selections longer than one word are ignored on purpose.
  • You need proper nouns and current slang. A fixed WordNet corpus has neither. There is a one-keypress web search for misses, and an optional online fallback, but that is a patch rather than a fix.
  • You are not on Windows. There is no macOS or Linux build, and there will not be one soon: it is AutoHotkey v2.
  • You need a signed installer for a managed machine. The download is unsigned, so SmartScreen warns on first launch. The builds are produced by GitHub Actions with a signed provenance attestation you can verify, which is not the same thing as code signing.

Where it wins

Long reading sessions across mixed applications, on a machine that may not have a connection, when you would rather not build a record of everything you did not know. One gesture, every program, nothing kept.

You can check the claims rather than trust them. The program is about eight hundred lines of AutoHotkey v2 on GitHub under the MIT licence, no binary is committed, and each release is built in CI with an attestation: gh attestation verify WordMeaning.exe --repo ishpreet36752/WordMeaning.

Questions

Is there a dictionary extension that works outside the browser?

An extension cannot reach outside its browser: no PDFs opened in another reader, no Word, no chat client. Lookups everywhere need a desktop program that watches the selection at the OS level.

What is the best free dictionary popup for Windows?

It depends on what you read. An extension is enough for web pages only. A desktop dictionary suits people who want a full reference tool. WordMeaning is the narrow option: one definition popup in every program, offline, storing nothing.

Can I run it alongside my existing dictionary?

Yes. It only reacts to a single-word selection and its one hotkey, Ctrl+Shift+D, is registered only while a popup is on screen, so it does not shadow that combination in other programs.

Is it really free, and what is the catch?

Free under the MIT licence, no account, no ads, no paid tier, no telemetry. The catch is the list above: definitions only, English only, single words only, Windows only.
