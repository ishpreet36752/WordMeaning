How to look up a word without leaving what you are reading

The tab switch costs more than the word does. Here is the two-minute setup that removes it, on any Windows program you can select text in.

Install a tray dictionary that watches text selection, then double-click the word. With WordMeaning running on Windows 10 or 11, selecting a single word in any program shows its part of speech, up to two meanings and an example sentence at your cursor. The popup closes when you click, switch windows, or after six seconds. There is no tab to open, nothing to paste, and no place lost in the page.

It is free, open source and works with no internet connection: installer (4.5 MB), portable .exe (9 MB).

Why the tab switch is the expensive part

Checking a word by hand is six moves: select it, copy it, find a free tab, type or paste, read, come back and find your line again. The reading stops for maybe twenty seconds, and the thread of the paragraph goes with it. Most people just guess the word instead, which is the outcome nobody wanted.

A selection-driven popup collapses those six moves into the one you were already making. You select the word because you were confused by it. That is the whole gesture.

The setup, once

  1. Install. Take the installer for a Start-menu entry and a clean uninstall, or the portable .exe if you prefer one file you can carry on a stick. Neither needs administrator rights or an AutoHotkey install.
  2. Get past SmartScreen. Windows shows an "unrecognised app" dialog for any program whose publisher has not bought a code-signing certificate. Click More info, then Run anyway.
  3. Select a word. Double-click it, or drag across it, in Chrome, Edge, Firefox, a PDF, Word, Notepad, Slack, an email. The definition appears where you are already looking.
  4. Keep reading. Click anywhere, Alt+Tab, or wait six seconds. Nothing is left on screen and nothing is left on disk.

Try it before you install anything. The front page runs the same rule in the browser: double-click a word in the demo window and the popup behaves exactly as the program does, including staying silent when you select two words.

Four habits that make it worth having

  • Read the hard paper anyway. The friction that stops people finishing a dense article is usually four unknown words, not the argument.
  • Select, don't guess. A definition at the cursor is cheap enough that you check the word you would otherwise have skipped over.
  • Use the miss. When a word is not in the dictionary the popup says so and offers Ctrl+Shift+D, which searches the web for it in your browser. The program never opens a browser by itself, so a name or a piece of new slang costs one deliberate keypress.
  • Leave it running. It is a tray program with no window. Turn it off from the tray menu when you are sharing your screen and want nothing popping up.

What it does not touch

Two questions people reasonably ask about anything that watches selected text.

Your clipboard. Reading the selection means copying it, so whatever you had copied is saved first and restored immediately afterwards, including when the lookup fails. Copy something, look up a word, paste: you get what you copied.

Your reading history. Looked-up words stay in memory for the session and are gone when the program exits. No history file, no log, no database, no telemetry, and by default no network request at all. The dictionary lives inside the program.

Questions

How do I check a word's meaning without opening a new tab?

Run a tray dictionary that watches text selection. With WordMeaning running, double-clicking a word in any Windows program shows its definition at the cursor for six seconds, so you never leave the page, PDF or document you are reading.

Does it work outside the browser?

Yes, that is the point of a tray program rather than an extension. The same double-click works in a PDF reader, Word, Notepad, an email client or a chat window, as long as the text can be selected.

Does it change my clipboard?

No. The selection is copied to read it, then your previous clipboard contents are put back immediately, including when the lookup fails.

What happens if I select a whole sentence?

Nothing at all. Anything longer than a single word is ignored: no popup, no error, and nothing sent anywhere.

Can I turn it off without uninstalling?

Yes. The tray menu has an Enabled toggle, and a separate Start with Windows toggle that writes only a per-user registry Run key.
