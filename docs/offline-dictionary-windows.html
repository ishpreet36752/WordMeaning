An offline dictionary for Windows that needs no internet

What to install when you want word meanings on a laptop with no connection, and how a whole dictionary fits inside a 4.5 MB download.

WordMeaning is a free offline dictionary for Windows 10 and 11. It sits in the system tray. Select a single word in any program, whether that is a browser, a PDF, Word or Notepad, and its definition appears at your cursor, then disappears after six seconds. About 86,000 WordNet 3.1 entries are compiled into the program, so lookups are answered on your own machine with no network connection, no account and no API key.

Download: installer (4.5 MB) or portable .exe (9 MB). Source is on GitHub under the MIT licence.

Why "offline" usually isn't

Most dictionary tools on Windows are a web page wearing a coat. A browser extension calls an API. A "desktop dictionary" downloads its data on first run and stops working when that host changes its terms. The failure shows up at the worst moment: on a plane, on hotel wifi that wants a login, on a locked-down work machine, or the week the free API tier disappears.

A dictionary that has to ask permission from a server is a dictionary that can be taken away. That is the reason the whole corpus ships inside this program instead of behind a request.

How the whole dictionary fits in the download

The data is generated from a checksum-pinned WordNet 3.1 release into one packed file: about 86,000 records, 7.5 MB, one per line, sorted. When the program is compiled, that file is embedded as a resource inside the .exe.

  • No parsing at startup. The program binary-searches the packed bytes in place: probe an offset, step to the next line, compare. It never builds a table of 86,000 entries in memory, which is why the tray app stays small.
  • No data written to disk. In the compiled build the dictionary is read straight out of the mapped executable image. The portable download really is one file.
  • Inflections cost almost nothing. Irregular forms (ran, mice) ship as redirect records; regular endings are stripped at lookup time by rule, so delimiter resolves through delimit without storing a separate entry. The popup shows the word it resolved to, so nothing is misattributed.

Install it and use it

  1. Download the installer for a Start-menu entry and a clean uninstall, or the portable .exe if you would rather copy one file to a USB stick. Neither needs administrator rights, and neither needs AutoHotkey installed.
  2. Windows SmartScreen will warn you on first launch, because the publisher has not paid for a code-signing certificate. Click More info, then Run anyway.
  3. A blue W appears in the tray. Double-click any word, or drag across it, in any program. The definition appears at the cursor.
  4. Click anywhere, switch windows, or wait six seconds and the popup is gone. If a word is missing, press Ctrl+Shift+D while the popup is up to search the web for it. The program never opens a browser on its own.

Test that it is really offline. Turn off wifi entirely, or pull the cable, and look up a dozen ordinary words. Every one still resolves. That is the whole point of the design, and it is worth checking yourself rather than believing this page.

What a bundled corpus cannot do

Honesty about the trade: a fixed 2011 corpus has no proper nouns, no brand names, and no recent slang. Selfie is not in it.

There are two answers, both under your control. Press Ctrl+Shift+D while a popup is up and the word goes to a web search in your browser, once, because you asked. Or switch on tray → Look up missing words online, which checks misses against an online dictionary. That switch is off by default, it is never written to a config file, and turning it off again clears the session cache. No socket is opened until you decide to open one.

Questions

Is there a dictionary for Windows that works without internet?

Yes. WordMeaning bundles about 86,000 WordNet 3.1 entries inside the program itself, so every lookup is answered from your own machine. No request leaves the computer for a definition, and it works with the network unplugged.

How big is the offline dictionary download?

The installer is about 4.5 MB and the portable single-file .exe is about 9 MB. Both contain the whole dictionary. There is no separate data download and no first-run sync.

Does it send the words I look up anywhere?

No. Lookups live in memory for the session and are gone when the program exits. Nothing is written to disk, logged or transmitted; there is no telemetry and no account. The clipboard is used to capture the selection and restored immediately afterwards, including when a lookup fails.

Which dictionary is it?

WordNet 3.1, Princeton University. Part of speech is chosen by tagged-corpus frequency rather than sense count, so better shows as an adjective even though it has more verb senses.

Does it work on macOS or Linux?

No. It is a Windows 10 and 11 program written in AutoHotkey v2, which is Windows-only.
